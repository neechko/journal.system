## Required Fixes (Priority Order)

### HIGH — Must Fix Before Any Delivery

1. **[HG-02] Mobile verification** — Test all pages at 320px, 375px, 414px. Fix horizontal overflow, text clipping, tap targets <44px.
2. **[HG-05] Logo placeholder** — Replace inline SVG logo in `PublicSiteHeader` with `[LOGO]` text marker or confirmed brand asset.
3. **[HG-07] Contrast audit** — Compute every text/background pairing in light + dark mode. Fix any below 4.5:1 (normal) / 3:1 (large).
4. **[HG-08] Placeholder dashboards** — Either implement editor/org dashboards or return 404/501 with "Not implemented" page.
5. **[HG-09] Loading/error states** — Add `loading.tsx` and `error.tsx` for all async routes; wrap fetches in `Suspense` boundaries.
6. **[HG-11] Focus ring on dark header** — Ensure `focus-visible` outline meets 3:1 on `bg-forest-deep` header.
7. **[HG-13] Dark mode full test** — Click through every page in dark mode; fix any broken styles.
8. **[HG-14] Recorded click-through** — Run build, click every interactive element, document results.
9. **[HG-18] False affordance on journal cards** — Remove `group-hover:shadow-lg` from non-interactive `<article>` wrappers; only links should have hover feedback.
10. **[HG-19] Prose image dimensions** — Add `width`/`height` or `aspect-ratio` to images in `dangerouslySetInnerHTML` content (or parse and augment).
11. **[HG-16] Direction documented** — **DONE** via `DESIGN.md`.
12. **[R-40] Performance** — Add `aspect-ratio` utility; verify no layout shift.

### MEDIUM — Purpose-Gate Compliance

13. **[PG-01] Remove decorative radial circles** — Home hero and journal header circles serve no hierarchy purpose.
14. **[PG-02] Audit arrow usage** — Standardize: arrows only for directional nav (back/forward/external). Remove from "Browse directory", "View journal profile".
15. **[PG-05] Arrow consistency** — "View DOI ↗" has arrow, "Download PDF" doesn't. Decide pattern.
16. **[QL-01] Standardize eyebrow tracking** — Use single token `--letter-spacing-wider` (0.05em) for all category labels.
17. **[QL-03] CTA audit** — Verify all CTAs specific (already PASS).
18. **[R-04] Icon relevance** — Document reason for each icon used (search, arrow, external, DOI, PDF, ORCID).

### LOW — Quality Locks

19. **[QL-01] Tokenize eyebrow tracking** — Add `--letter-spacing-eyebrow: 0.05em` token, replace all inline values.
20. **[R-31] Decision log** — Ensure all future UI decisions have one-line reason in PR/commit.
21. **[R-23] Asset placeholders** — Audit all assumed assets (avatars, logos, images) — replace with honest placeholders.
