# Domain Glossary

| Istilah | Definisi kerja |
|---|---|
| Platform | Sistem inti yang meng-host banyak organisasi dan jurnal. |
| Organization / Publisher | Institusi atau penerbit yang mengelola satu atau lebih jurnal. |
| Journal | Publikasi serial dengan scope, ISSN, kebijakan, board, dan arsip. |
| Issue | Edisi jurnal; dapat berada dalam volume dan memiliki urutan/tanggal terbit. |
| Article | Karya ilmiah konseptual beserta metadata dan kontennya. |
| ArticleVersion | Versi tertentu dari artikel/record konten, dengan provenance. |
| Publication | Kejadian/manifestasi artikel yang diterbitkan dalam jurnal/issue atau ahead-of-print. |
| Submission | Naskah yang dikirim author ke jurnal untuk dipertimbangkan. |
| ManuscriptFile | File submission/revisi yang diunggah, bukan otomatis versi artikel terbit. |
| EditorialAssignment | Penugasan editor untuk menangani submission. |
| ReviewAssignment | Penugasan reviewer untuk submission tertentu. |
| ReviewReport | Laporan/rekomendasi reviewer. |
| EditorialDecision | Keputusan editor yang berwenang; terpisah dari rekomendasi reviewer. |
| Production | Tahap persiapan konten setelah acceptance. |
| Proof | Representasi yang diperiksa author/editor sebelum publikasi. |
| DOI | Persistent identifier yang status registrasinya harus diverifikasi ke registrar. |
| JATS | Journal Article Tag Suite, standar XML untuk struktur dan pertukaran artikel ilmiah. |
| Tenant scope | Batas organisasi/jurnal yang menentukan data apa yang boleh diakses aktor. |
| Audit event | Catatan append-only tentang aksi atau perubahan penting. |
| Ahead-of-print | Artikel diterbitkan sebelum penempatan final di issue, sesuai kebijakan jurnal. |
| Correction / Retraction | Catatan koreksi atau pencabutan publikasi yang harus terhubung ke rekam artikel. |

Jika istilah baru muncul, tambahkan di sini dan gunakan satu istilah konsisten dalam kode, API, UI, dan test.
