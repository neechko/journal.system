# Contributing

1. Read `AGENTS.md` and the relevant docs before coding.
2. Create a focused branch and keep a task scoped to one purpose.
3. For non-trivial features, link an accepted feature specification and list acceptance criteria.
4. For architecture changes, add/update an ADR.
5. Add tests at the correct layer; include authorization and tenant-isolation negatives where applicable.
6. Run the repository's documented lint, typecheck, tests, and build commands.
7. Update documentation when contracts, workflows, schema, security posture, or operational behavior changes.
8. Open a pull request with summary, evidence, risks, and migration notes.

Do not commit secrets, real manuscripts, personal data, reviewer reports, customer files, or production database exports.
